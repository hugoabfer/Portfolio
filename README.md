## Main Projects

### 1. Asset Allocation: Naive vs Markowitz vs Risk Parity (Python)
**File:** `portfolio_optimization_markowitz_rp.py`
* **Overview:** A comparative analysis of different asset allocation strategies. The script tests how portfolios perform and handle risk based on three approaches:
  * **Naive (1/N):** Classic equally weighted portfolio.
  * **Markowitz (Mean-Variance):** Mathematical optimization to find the efficient frontier and maximize the Sharpe ratio.
  * **Risk Parity:** An approach where weights are adjusted so that every asset contributes equally to the overall portfolio risk.

### 2. Multivariate Volatility Modeling (R)
**File:** `dcc_garch_model.R`
* **Overview:** Implementation of a **DCC-GARCH** (Dynamic Conditional Correlation) model. I wrote this script to analyze how correlations and volatilities between different financial assets evolve over time. This kind of modeling is extremely useful for dynamic risk management and calculating VaR (Value at Risk) in diversified portfolios.
